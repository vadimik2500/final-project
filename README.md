# Финальный проект: Сервис задач (Task Service)

## Описание
Микросервисная архитектура для управления задачами. Состоит из 3 сервисов:
1. **API Gateway** (Nginx) — маршрутизация запросов.
2. **API Service** (Python) — бизнес-логика.
3. **PostgreSQL** — база данных.

## Запуск
```bash
docker compose up -d --build
